- **Docker image tag (`opencode-qwen-prompt-dev:latest`) build race across worktrees (deferred).** The image is deliberately global/shared across all worktrees (rebuilding a multi-GB toolchain image per worktree would be wasteful) — so it sits outside the per-worktree isolation `docker/dev.sh` gives everything else.
