# What this project is

`opencode-toolkit` (renamed from `opencode-qwen-prompt` on 2026-09-19, see CLAUDE.md) is a general opencode tooling workspace, not a single-purpose repo: a system-prompt override for a specific Qwen3.6-35B-A3B/vLLM deployment on a network-isolated Windows machine (the piece that was built first and originally gave the repo its old name), several standalone custom opencode hook plugins, a practical script for using opencode to generate an architecture map of a large codebase, and MCP servers (`mcp-servers/oracle/`, `mcp-servers/loki/`, `mcp-servers/java-lsp/`, `mcp-servers/spring-lsp/`) for LAN-internal ops tooling and Java/Spring code intelligence, with more planned (see `mcp-servers/TODO.md`). The prompt override isn't the whole scope, and hasn't been since before the rename — the other pieces are real parts of the project, not unrelated hitchhikers that happen to share a git history.

This file is deliberately thin: `README.md` (what/why, repo layout) and `CLAUDE.md` (how to work on it, hard-won lessons, preferences) are the authoritative, actively-maintained sources — read those fresh rather than trusting this note for anything beyond the orientation above.
