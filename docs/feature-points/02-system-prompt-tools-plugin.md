# system-prompt-tools.ts plugin

Source lives in `deploy/system-prompt-tools.ts`. Hooks `experimental.chat.system.transform` to dump the fully-assembled system prompt actually sent to the model (all blocks, including opencode's own `<env>` block) to `~/.local/share/opencode/last-system-prompt.txt` on every request — the only way to confirm the override is really taking effect against the real model, since there's no other visibility into what gets sent. Written in TypeScript against `@opencode-ai/plugin`'s `Plugin` type (the official SDK), matching `plugins/hook-logger.ts`/`plugins/llm-review-gate.ts`.

**Packaging (changed 2026-09-15):** ships as its own npm package — `deploy/package.json` + the committed, pre-packed `deploy/opencode-system-prompt-tools-1.0.0.tgz` (regenerate with `npm pack` in `deploy/` after editing the source; `tests/unit/plugins-tarball.test.mjs` fails the build if it drifts) — installed on the target machine via a `file:` npm spec in `opencode.json`'s `plugin` array (SETUP.md step 4), the same mechanism `plugins/opencode-hook-plugins-1.0.0.tgz` uses for `hook-logger.ts`/`llm-review-gate.ts` (SETUP.md step 5). Previously this shipped as a raw `.ts` file copied directly onto the target machine with a hand-derived absolute path wired straight into `plugin` — switched to match the npm-package pattern instead, since a versioned local tarball beats a bare file path that has to be manually re-derived per machine. Confirmed against a real opencode install (not just read from its docs) that a `file:` spec pointing at a local tarball installs and resolves correctly with zero network access — see `docker/docker-notes.md`'s "Plugin dependency pre-warming" section for how that was verified. Tradeoff: unlike `deploy/system-prompt.txt`, editing `deploy/system-prompt-tools.ts` no longer takes effect immediately in the docker sandbox via the live bind mount — it needs `npm pack` plus an image rebuild first, same as `plugins/`'s packages already required.

**Tested:** `tests/unit/system-prompt-tools.test.mjs` — dump content/header format (model/session/block-count), and that each request overwrites rather than appends (the dump always reflects the latest request). Its shipped packaging is covered by `tests/unit/plugins-tarball.test.mjs`, same as `plugins/`'s tarball.
