# system-prompt-tools.ts plugin

Lives in `deploy/`. Hooks `experimental.chat.system.transform` to dump the fully-assembled system prompt actually sent to the model (all blocks, including opencode's own `<env>` block) to `~/.local/share/opencode/last-system-prompt.txt` on every request — the only way to confirm the override is really taking effect against the real model, since there's no other visibility into what gets sent. Written in TypeScript against `@opencode-ai/plugin`'s `Plugin` type (the official SDK), matching `plugins/hook-logger.ts`/`plugins/llm-review-gate.ts` — unlike those, it ships as a standalone `.ts` file copied directly onto the offline target machine (see SETUP.md step 4), not packaged via `plugins/`'s npm tarball, since opencode's own plugin loader (Bun-based) loads local `.ts`/`.js` plugin files directly with no build step either way.

**Tested:** `tests/unit/system-prompt-tools.test.mjs` — dump content/header format (model/session/block-count), and that each request overwrites rather than appends (the dump always reflects the latest request).
